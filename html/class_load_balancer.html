Detailed Description

Manages a request queue and a pool of servers for a specific JobType.

A LoadBalancer maintains:

  • A FIFO queue of requests
  • A vector of servers that process those requests
  • Configuration values loaded from a config file
  • Simulation statistics (generated, accepted, rejected, completed, scaling)
  • Firewall state (rate-limiting and IP blocking)

In this simulation, a management load balancer may generate and route requests to other load balancers (e.g., Streaming and Processing) based on request type.

Generates a request with a given probability.

When a request is generated, its IPs are sampled from genRange and its time is sampled uniformly from [minRequestTime, maxRequestTime]. If vFlag is true, the request's source IP (inIP) is forced to be chosen from the provided valid list.

Parameters

vFlagIf true, force the source IP to be chosen from valid.
validA list of valid source IPs to sample from when vFlag is true.
Returns
A generated Request; may return a default/empty request if none generated.

int LoadBalancer::tick ( std::vector< LoadBalancer * > LBs)

Advances the simulation by one tick for this load balancer and provided LBs.

Increments time, decrements active requests on servers, marks completed requests, and dispatches queued requests onto idle servers. Also applies an optional sleep to simulate a clock period.
