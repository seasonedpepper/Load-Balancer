enum class JobType
strong

Represents the category of work a request or server handles.

JobType defines the classification of a request within the system. These values are used to route requests to the appropriate LoadBalancer and Server instances.

The numeric assignments are explicitly defined to allow deterministic integer conversions when scaling or routing.
