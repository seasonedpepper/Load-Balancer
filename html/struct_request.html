Detailed Description

Represents a single network request handled by the system.

A Request contains:

  • Source IP address (inIP)
  • Destination IP address (outIP)
  • Processing time (time)
  • Associated JobType

Requests are generated by the management load balancer and routed to either Streaming or Processing load balancers depending on type.
